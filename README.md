# Pterodactyl 面板

Pterodactyl® 是一個免費、開源的遊戲伺服器管理面板，使用 PHP、React 與 Go 開發。
Pterodactyl 以安全性為設計核心，透過隔離的 Docker 容器來執行所有遊戲伺服器，同時向終端使用者提供美觀且直覺的使用者介面。

別再委屈自己使用次等方案，讓遊戲伺服器在你的平台上成為「一等公民」。

### 支援的遊戲

Pterodactyl 透過 Docker 容器隔離每個實例，因此能支援各式各樣的遊戲。  
這讓你能執行遊戲伺服器，而不需要在主機上額外安裝一大堆相依套件，避免系統膨脹。

部分核心支援的遊戲包含：

* Minecraft — 包含 Paper、Sponge、Bungeecord、Waterfall 等等
* Rust
* Terraria
* Teamspeak
* Mumble
* Team Fortress 2
* Counter Strike: Global Offensive
* Garry's Mod
* ARK: Survival Evolved

除了標準的「nest」所支援的遊戲之外，社群也持續推進這套軟體的極限，並提供更多由社群製作的遊戲可用。其中一些例子包含：

* Factorio
* San Andreas: MP
* Pocketmine MP
* Squad
* Xonotic
* Starmade
* Discord ATLBot, 以及大多數 Node.js/Python 的 Discord 機器人
* [以及更多...](https://eggs.pterodactyl.io)
